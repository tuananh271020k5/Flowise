# B-017 — Tạo Knowledge Template Có Retrieval và Bổ Sung Knowledge Spec & Readiness

**Status:** completed. **Tương ứng:** PH4-T03 và PH4-T04 trong [PLAN_TONG_HOP.md](../../PLAN_TONG_HOP.md).
**Phụ thuộc:** [B-016](B-016.md) (Bộ tài liệu thử và Document Store Service).

## Mục tiêu và Tình huống Người dùng

Mở rộng năng lực của hệ thống Chat-to-Agent Builder từ **Assistant** sang **Knowledge Agent** (RAG Retrieval-Augmented Generation):

1. **Tạo Knowledge Template Có Retrieval (PH4-T03):**
    - Xây dựng template mới `knowledgeTemplate.v1.ts` theo chuẩn Agentflow V2:
      - Tạo đồ thị gồm Start Node (version 1.4) → Agent Node (version 3.2).
      - Liên kết Agent Node với Document Store Tool / Retriever Tool để truy xuất các chunks tài liệu liên quan khi trả lời câu hỏi.
      - Pinned Chat Model node với temperature 0.2 giúp giảm thiểu tối đa ảo giác (hallucination).
      - Nhúng nguyên tắc RAG: bắt buộc trích dẫn nguồn, từ chối suy diễn nếu thiếu căn cứ.
      - Thẩm định toàn bộ nodes qua `nodeRegistry` và kiểm tra hợp lệ qua `flowValidator`.

2. **Bổ Sung Knowledge Spec và Quy Tắc Readiness (PH4-T04):**
    - Mở rộng xử lý `kind: 'knowledge'` trong `agentSpec.ts` và `readiness.ts`.
    - Khi người dùng muốn tạo Knowledge Agent (hỏi đáp theo tài liệu):
      - Hệ thống kiểm tra trường bắt buộc `dataSources` (phải có ít nhất 1 nguồn tri thức hợp lệ trong workspace).
      - Nếu thiếu nguồn tri thức, `computeReadiness` báo thiếu `dataSources`, gán `reasonCodes: ['MISSING_KNOWLEDGE_STORE']` và chặn build (`buildReady: false`).
      - Collector trích xuất được yêu cầu đính kèm tài liệu từ chat tiếng Việt và tự động hướng dẫn người dùng chọn kho tài liệu phù hợp (ví dụ kho fixture Quy chế nội bộ).
