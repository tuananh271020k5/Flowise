## Mục tiêu và Tình huống Người dùng

Mở đầu Phase 6 (API, SQL & Tích hợp mở rộng):

1. **API Connector Registry & Operation Allowlist (PH6-T01):**
    - Cho phép đăng ký và quản lý các API connector an toàn trong workspace.
    - Quản lý allowlist các operations (GET/POST/PUT...), tham số đầu vào/ra được phép; tuyệt đối không để LLM tự ý gọi URL tùy ý ngoài danh mục được duyệt (SSRF Defense).
    - Ngăn chặn triệt để thao tác thay đổi dữ liệu (POST/PUT/DELETE/PATCH) trong ngữ cảnh readonly.

2. **API Agent Spec & Thu Thập Yêu Cầu (PH6-T02):**
    - Mở rộng AgentSpec để hỗ trợ cấu hình `apiConnectors`, endpoint refs, authentication headers/tokens qua Credential Store của Flowise.
    - Collector trích xuất nhu cầu tích hợp API từ hội thoại tiếng Việt của người dùng ("gọi API thời tiết", "kết nối API").

3. **API Readonly Template & Compiler (PH6-T03):**
    - Xây dựng template và compiler sinh luồng Agentflow V2 tích hợp Custom Tool hoặc API Request Node (`requestsGet`).
    - Áp dụng cơ chế an toàn readonly đối với các tác vụ truy vấn dữ liệu bên ngoài.
