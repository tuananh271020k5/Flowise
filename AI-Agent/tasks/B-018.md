2. **Hiển Thị Câu Trả Lời và Nguồn Trích Dẫn (PH4-T06):**

    - Bổ sung cấu trúc phản hồi `sourceDocuments` / `citations` vào API chat test assistant và UI hiển thị trích dẫn trực quan.
