# B-003 — Định nghĩa AgentSpec v1 và Quy tắc Readiness

**Status:** not_started. **Tương ứng:** PH1-T01 và PH1-T02 trong [PLAN_TONG_HOP.md](../../PLAN_TONG_HOP.md).
**Phụ thuộc:** [B-002](B-002.md) đã chốt phạm vi trợ lý Onboarding và các kịch bản demo tại [B-002_DECISIONS.md](../context/B-002_DECISIONS.md).

## Mục tiêu và Tình huống Người dùng

Định nghĩa schema chuẩn hóa (`AgentSpec v1`) bằng Zod/TypeScript cho loại trợ lý cơ bản (_assistant_) và hàm đánh giá mức độ sẵn sàng (_readiness rules_).
Mục tiêu là giúp hệ thống xác định chính xác khi nào cuộc hội thoại thu thập yêu cầu đã có đủ thông tin để tự động kích hoạt build (`buildReady: true`), khi nào còn thiếu dữ kiện (`missingFields[]`) để hỏi tiếp, và ngăn ngừa việc model tự suy diễn các trường thông tin quan trọng.

## Context Tối thiểu

`AGENTS.md` → `AI-Agent/state/project.json` → file này → `AI-Agent/context/B-002_DECISIONS.md` → `AI-Agent/plans/CONTRACTS.md` (Mục 1: AgentSpec v1 dự kiến).

## Tiêu chí Nghiệm thu

-   [ ] Schema `AgentSpec v1` có version, giới hạn độ dài/kiểu dữ liệu, logical model ref (`default-builder-model`), không chứa raw secret hay tenant ID giả lập.
-   [ ] Hàm đánh giá `computeReadiness(spec)` trả về kết quả xác định (deterministic object): `specReady`, `buildReady`, `testReady`, `missingFields[]`, `assumptions[]`, `reasonCodes[]`.
-   [ ] Bộ unit tests kiểm tra:
    -   Spec hợp lệ đầy đủ → `buildReady: true`.
    -   Spec thiếu mục tiêu/tên/ngôn ngữ → `buildReady: false`, liệt kê đúng `missingFields`.
    -   Spec chứa trường lạ hoặc injection → Bị Zod/Validator từ chối.
-   [ ] Chạy unit tests pass 100%, không ảnh hưởng đến mã nguồn runtime hiện có.

## Phạm vi Cho phép (Allowed Scope)

Các file schema và validator mới thuộc module Builder (dự kiến đặt trong thư mục mới hoặc `packages/server/src/services/agent-builder/` hoặc package chuyên dụng), bộ unit tests tương ứng. Chưa thêm giao diện UI hay sửa đổi endpoint database.
