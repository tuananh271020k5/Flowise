## Mục tiêu và Tình huống Người dùng

Khép lại Phase 6 (API, SQL & Tích hợp mở rộng):

1. **Custom Tools Builder & Runtime Sandbox An Toàn (PH6-T09):**
    - Cho phép người dùng khai báo hoặc sinh Custom Tools có code JavaScript/TypeScript được kiểm soát.
    - Bộ phân tích AST & Sandbox ngăn chặn truy cập tài nguyên nhạy cảm (chặn `process.exit`, `child_process`, `fs` trái phép, network ngoài allowlist).

2. **Webhook Ingestion & Event Listener (PH6-T10):**
    - Hỗ trợ cơ chế Webhook nhận dữ liệu và sự kiện từ hệ thống bên ngoài để kích hoạt hoặc cập nhật Agent.
    - Xác thực chữ ký webhook (HMAC signature verification) và bảo vệ bằng Rate Limiting.

3. **Bộ Eval E2E Kết Hợp Đa Nguồn (API + SQL + Custom Tools) (PH6-T11):**
    - Kiểm thử kịch bản phức tạp: một Agent tích hợp đồng thời API thời tiết, cơ sở dữ liệu SQL bán hàng và công cụ tính toán / custom tool.
    - Đảm bảo tính toàn vẹn và độ trễ hợp lý trong môi trường runtime.

4. **Đóng Gói Builder Operations Thành Chuẩn MCP Server Tools (PH6-T12):**
    - Đóng gói các tính năng cốt lõi của Builder thành MCP Tools (Model Context Protocol): `agent_create_session`, `agent_build`, `agent_publish`, `agent_eval`.
    - Chuẩn hóa schema, adapter, quyền workspace, và idempotency.
