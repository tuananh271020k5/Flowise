**Status:** not_started. **Tương ứng:** PH6-T04, PH6-T05, PH6-T06, PH6-T07 và PH6-T08 trong Master Plan (Phase 6).

## Mục tiêu và Tình huống Người dùng

Tiếp tục Phase 6 (API, SQL & Tích hợp mở rộng):

1. **Bộ Eval API & Xử lý lỗi Connector (PH6-T04):**
    - Kiểm thử các tình huống biên của API Connector: timeout, 401 Unauthorized, 403 Forbidden, 429 Rate Limited, payload không đúng cấu trúc schema.
    - Xây dựng cơ chế fallback và thông báo lỗi rõ ràng bằng tiếng Việt cho người dùng.

2. **Thiết kế SQL Executor & Tài khoản Readonly (PH6-T05):**
    - Thiết kế cơ chế kết nối CSDL có kiểm soát (Readonly DB Connection).
    - Ngăn chặn câu lệnh can thiệp cấu trúc hoặc thay đổi dữ liệu (chặn tuyệt đối DROP, TRUNCATE, DELETE, UPDATE, INSERT, ALTER).

3. **SQL Agent Spec, Dataset Scope & Row Limit (PH6-T06):**
    - Mở rộng AgentSpec hỗ trợ loại Agent `sql-readonly`, cấu hình danh sách bảng được phép đọc, giới hạn dòng trả về (`rowLimit: 50/100`).
    - Collector trích xuất nhu cầu phân tích cơ sở dữ liệu qua hội thoại tiếng Việt.

4. **SQL Template & Compiler (PH6-T07):**
    - Template và Compiler sinh luồng Flowise Agentflow V2 tích hợp Node thực thi SQL có ràng buộc readonly và row limit.

5. **Bộ Eval Kịch Bản SQL & Negative Test Cases (PH6-T08):**
    - Bộ 10+ kịch bản kiểm thử SQL: truy vấn thống kê, tìm kiếm bảng, và negative test cases (injection, cố tình chạy UPDATE/DELETE/DROP).
