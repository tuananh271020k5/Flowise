## Mục tiêu và Tình huống Người dùng

Tiếp tục Phase 6 (API, SQL & Tích hợp mở rộng):

1. **Bộ Eval API & Xử lý lỗi Connector (PH6-T04):**
    - Kiểm thử các tình huống biên của API Connector: timeout, 401 Unauthorized, 403 Forbidden, 429 Rate Limited, payload không đúng cấu trúc schema.
    - Xây dựng cơ chế mapping lỗi và thông báo thân thiện bằng tiếng Việt rõ ràng, bảo vệ an toàn secrets.

2. **Thiết kế SQL Executor & Tài khoản Readonly (PH6-T05):**
    - Xây dựng `sqlExecutorService.ts`: Quản lý cấu hình kết nối CSDL (SQLite, Postgres, MySQL) có phân quyền cách ly theo workspace.
    - AST / Regex Safety Guard: Chặn 100% câu lệnh DDL/DML gây hại (`DROP`, `TRUNCATE`, `ALTER`, `CREATE`, `INSERT`, `UPDATE`, `DELETE`, `GRANT`, `REVOKE`, multi-statement injection `;`, comment bypass).
    - Table Allowlist: Chỉ cho phép truy vấn các bảng được cấp phép trong `allowedTables`; chặn truy cập bảng hệ thống (`sqlite_master`, `pg_catalog`).
    - Row Limit: Tự động gán hoặc ép giới hạn số dòng (mặc định 50, tối đa 100).

3. **SQL Agent Spec, Dataset Scope & Row Limit (PH6-T06):**
    - Mở rộng AgentSpec hỗ trợ `kind: 'sql-readonly'`, cấu hình `sqlConfig` (`allowedTables`, `rowLimit`, `databaseType`).
    - Collector trích xuất nhu cầu phân tích cơ sở dữ liệu qua hội thoại tiếng Việt không hỏi lặp lại.

4. **SQL Template & Compiler (PH6-T07):**
    - Xây dựng `sqlTemplate.v1.ts` và tích hợp vào `compiler.ts` sinh luồng Flowise Agentflow V2 tích hợp Node `customTool` (SQL Readonly Query Tool) và `agentAgentflow`.
    - Tự động nhúng quy tắc an toàn bảo vệ CSDL (SQL Readonly Rules) vào System Prompt.

5. **Bộ Eval Kịch Bản SQL & Negative Test Cases (PH6-T08):**
    - Bộ 10 kịch bản kiểm thử SQL: truy vấn đơn giản, thống kê group by/count, join bảng allowlist, và các negative security test cases (injection, cố tình chạy UPDATE/DELETE/DROP).
