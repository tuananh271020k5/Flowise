# B-008 — Định nghĩa AgentPlan và Viết Compiler Deterministic

**Status:** not_started. **Tương ứng:** PH2-T03 và PH2-T04 trong [PLAN_TONG_HOP.md](../../PLAN_TONG_HOP.md).
**Phụ thuộc:** [B-007](B-007.md) (Assistant Template v1 và Node Registry allowlist).

## Mục tiêu và Tình huống Người dùng

Phát triển tầng trung gian `AgentPlan` và bộ biên dịch tất định (`Deterministic Compiler`) để biến đổi `AgentSpec v1` thành cấu trúc Flowise Agentflow V2 hoàn chỉnh mà không cần dựa vào LLM sinh raw graph:

1. **Định nghĩa AgentPlan & Validation (PH2-T03):** Lập kế hoạch kiến trúc chi tiết từ Spec (trỏ tới template phù hợp, phân giải capabilities, ánh xạ model provider, tools và data sources). Thẩm định tính hợp lệ của Plan trước khi đưa vào compiler.
2. **Deterministic Compiler (PH2-T04):** Chuyển đổi AgentPlan thành `nodes`, `edges`, và `flowConfig` ổn định (cùng một input Spec luôn sinh ra cùng một cấu trúc graph). Đảm bảo toàn bộ node sinh ra đều vượt qua Node Registry whitelist từ [B-007](B-007.md).
